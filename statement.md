# Project Statement

## Project Title
HostelHub - Smart Hostel Utility and Expense Manager

## Problem Statement
Hostel students regularly share food bills, groceries, chores and common items. Keeping track of these through memory or chat messages can become confusing. HostelHub is a simple Python program that keeps these tasks organized in one place.

## Scope
The project focuses on a small hostel room or student group. It manages shared expenses, calculates balances, rotates chores, tracks shared items, searches records and gives basic spending statistics.

## Target Users
College students living in hostels, PGs or shared flats.

## High-Level Features
1. Expense management
2. Balance and settlement calculation
3. Chore rotation
4. Shared item tracking
5. Search
6. Basic analytics

## Limitations
The program is offline, uses local files and is intended for a small group. It does not use accounts, online payments or a database.
